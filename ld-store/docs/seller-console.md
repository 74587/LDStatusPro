# 卖家后台：Paper Console

> 范围：`/seller` 壳层与全部卖家子页。  
> 原则：保留士多海军蓝 + 纸面 + 青绿，把密度、组件和页面骨架统一成经营台账。  
> 不要改成通用深色 SaaS，也不要把帮助中心的长文气质当工作台。

## 1. 问题

卖家后台同时叠了三套产品语言：

| 语言 | 表现 | 典型页面 |
|---|---|---|
| A. 台账 | 海军侧栏、纸面、工具栏 + 表格 | 订单、物品、退款、优惠券 |
| B. 商城页塞进 `/seller` | `page-container`、大号 `h1`、玻璃液态 Tab | 收款、小店、通知、发布/编辑 |
| C. 营销落地页 | 大 Hero、口号、时间线 | 经营概览「经营笺」、发货与履约、商家服务 |

用户感知是布局乱、样式不统一、看起来奇怪。根因不是某一页丑，而是没有单一页面骨架。

具体症状：

- 顶栏已有 `h1`，页内再写一遍标题。
- 壳层告警与页内 Hero 说同一件事，主按钮出现多次。
- 侧栏「回广场」与顶栏「物品广场」、两侧头像重复。
- 控件家族混乱：LiquidTabs / 原生 select / AppSelect / 各页自造按钮。
- 文案语言不统一：`AFTER-SALES LEDGER`、营销口号、中文台账混用。
- 工作台密度偏杂志：衬线大标题、172px Hero、大留白。
- 内容宽度跳变：`seller-main` 1480px，部分页 `page-container` 1200px。
- 平板 <1024 直接收成抽屉，横屏只剩汉堡。

## 2. 目标形态

士多卖家后台 = 纸质台账 + 海军工具条。有品牌，但不抒情。有密度，但不拥挤。

### 2.1 一页一套骨架

```text
SellerPage
├── 顶栏 h1（唯一标题，来自路由 meta.title）
├── 可选：一句 14px 说明（SellerPageToolbar，不用英文 eyebrow）
├── 可选：一行主操作（发布 / 刷新 / 开通）
├── SellerFilterBar（分段 Tab + 搜索 + 筛选，同一行高）
├── SellerSurface（表 / 表单 / 看板）
└── SellerPagination
```

禁止：页内第二个 `h1`、营销 Hero、与壳层重复的告警条。

### 2.2 桌面信息架构

```text
工作台    经营概览
交易      订单管理 · 退款售后
商品      我的物品          ← 「发布物品」是页内主按钮，不占导航
经营      优惠券 · 推广 · 小店
设置      发货与履约 · 通知 · 收款
```

- 「商家服务」对卖家显示为「推广」。
- 「发货与履约」未确认时是阻断流（壳层横幅指向本页）；确认后本页收成状态条 + 记录表，仍可从设置进入。
- 当前页若已是履约页，壳层不再重复同一句告警。

### 2.3 自适应导航

| 宽度 | 导航 |
|---|---|
| ≥1024 | 248px 完整侧栏 |
| 768–1023 | 72px 图标轨，标签用 `title` / `aria-label` |
| <768 | 底栏四项：概览、订单、物品、我的；顶栏去掉回广场 |

「我的」收纳：退款、推广、优惠券、小店、履约、通知、收款、回广场。

### 2.4 组件套件

| 组件 | 职责 |
|---|---|
| `SellerButton` | primary / secondary / danger / ghost。主按钮海军实心 |
| `SellerTabs` | 卖家域分段控件，替换 LiquidTabs |
| `SellerField` | 标签 + 控件 + 帮助/错误 |
| `SellerFilterBar` | 唯一筛选容器 |
| `SellerDataTable` | 已有；行内最多一个实心按钮 |
| `SellerStatusBadge` | 已有；唯一状态徽章 |
| `SellerAlert` | 信息 / 警告 / 危险，壳层与页内共用 |
| `SellerEmpty` | 图标 + 一句 + 一个动作 |

卖家域禁止再引入 `LiquidTabs`。买家订单、首页分类等消费者界面仍用液态 Tab。

### 2.5 类型与 token

| 角色 | 规格 |
|---|---|
| 品牌字标 | 17 / 600，衬线 |
| 页面标题（仅顶栏） | 20 / 600，无衬线 |
| 区块标题 | 16 / 600，无衬线 |
| 正文 | 14 / 400，行高 1.5 |
| 表格 / 数字 | 13 / 500，`tabular-nums` |
| 辅助 | 12 / 500 |

半径：控件 8 · 卡片 12 · 胶囊 999。间距：4 / 8 / 12 / 16 / 24。阴影仅 `sm` / `md`。

卖家域只消费 `--seller-*` 语义 token，组件样式不写 `--palette-hex-*`。

## 3. 页面改造

**经营概览**  
新卖家保留开张清单。老卖家首屏改为可点积压（待发货 / 待退款 / 低库存或售罄 / 审核），再是 KPI 与趋势。「今日经营笺」改为一行状态摘要。

**订单 / 物品 / 退款**  
已接近目标，统一改用 `SellerTabs` 与套件按钮。退款 eyebrow 改为中文「退款台账」。

**发货与履约**  
未确认：工作面是规则要点 + 单一确认动作，不与壳层横幅重复。  
已确认：状态条 + 数字 + 记录表；三条时限放进「查看规则」。

**推广（原商家服务）**  
去掉 C 端口号。首屏为开通入口 + 名额/记录 Tab，购买保持原流程。

**优惠券**  
去掉链到买家券包的「我的优惠券」。创建/列表继续用同一工具栏。

**收款 / 小店 / 通知**  
迁到同一说明条 + 表单/状态卡片，去掉页内重复 `h1`。

**发布 / 编辑**  
保持宽表单 + 右侧摘要；主提交按钮与套件 primary 对齐。

## 4. 验收

任意卖家页截图应同时满足：

1. 标题只出现一次，且在顶栏  
2. 主按钮只有一个，实心海军  
3. 筛选条高度、圆角、间距与订单页一致  
4. 状态只来自 `SellerStatusBadge`  
5. 桌面是表，手机是卡，没有横向撑破  
6. 从订单跳到收款，不再觉得换了一个网站  
7. 异常告警全局最多一条  
8. 新卖家看懂开张，老卖家 3 秒内看到积压数字
